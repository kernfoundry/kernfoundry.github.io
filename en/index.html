What it does

Six jobs it takes over

One file starts the chain: calculation, drafting, and a record of what happened. Only what you need is used.

01

Attendance

Reads .xlsx and CSV as they are and counts one rate per student, with absence and late counts.

02

Parent notes

Drafts an absence or monthly note from the rate. Nothing is sent by the program itself.

03

Tuition settlement

Compares charge and payment and classifies each student as paid, partial, unpaid or overpaid.

04

Edge-case warnings

Empty cells, text in numeric columns, a total of zero, attendance above the total: set aside and reported.

05

Run record and undo

Every run leaves a record, and only the files that run produced are reverted.

06

Personal data blocked

Phone numbers, resident registration numbers and card numbers are blocked inside a note.

Every run checks 76 items on its own. The full screen is on the results page.

FAQ

Questions owners ask before starting

In the order owners usually check them.

Will it read the spreadsheet we already keep?

Yes. Put in the .xlsx file you already use and it reads the first sheet. Column names such as name, attended or total classes are found even when they differ. Only the older .xls format needs saving once as .xlsx.

Do we have to install anything?

No install and no server. A web browser is all you need.

What about personal data?

Files are processed on the academy computer and are not transmitted anywhere. If a note would contain a phone number, resident registration number or card number, it is blocked automatically.

Do parents need an app?

No. The notes come out as text that can be sent by SMS or a messaging channel. Sending stays with the academy.

Does it match our class and term system?

Attendance counts and totals are read from your file. Where a different scheme is used, such as per-term packages, the calculation is agreed during onboarding.

How much does it cost?

KRW 39,000 a month (up to 100 students) or KRW 59,000 a month (no limit), VAT excluded. The first 30 days are free and there is no fixed term. Messages are metered at KRW 10–14 each and our markup is zero.

Can we stop if it does not fit?

There is no fixed term. You can stop at any time, and unused remaining days are refunded pro rata.

Can a mistake be undone?

Yes. Only the output of a single run is reverted; nothing else is touched.

Just tell us your file format

We will confirm whether it fits. You can send it with no commitment.
